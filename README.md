# Kana Practice

A lightweight, fully responsive single-page web application designed for learning and practicing Japanese **Hiragana** and **Katakana**. Built with pure HTML, CSS, and modern JavaScript with zero external build steps or dependencies.

## Features

* **Complete Character Sets**: Covers basic 46 characters, voiced (*dakuten/handakuten*), combined (*yoon*), and foreign sound forms.
* **Multiple Practice Modes**:
  * **Chart**: Interactive character grid with mastery indicators and audio pronunciation.
  * **Read It**: Type the Romaji transcription for a given Kana glyph.
  * **Pick It**: Multiple-choice quiz alternating between reading and writing directions.
  * **Write It**: Canvas-based drawing pad with optional guide overlays to practice stroke writing.
  * **Progress**: Comprehensive stats grid tracking accuracy, streaks, and trouble characters.
* **Spaced Repetition Algorithm**: Intentionally brings back characters you miss more frequently.
* **Persistent Storage**: Automatically saves your mastery progress and preferences using browser storage.
* **Customization**: Switch between Japanese typography styles (**Mincho**, **Gothic**, and **Rounded**).

## Local Development & Usage

Because this application is self-contained entirely within a single `index.html` file, running it locally requires no installation or node modules.

1. Save the code as `index.html`.
2. Double-click the file to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
