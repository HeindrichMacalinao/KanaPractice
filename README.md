# Kana Practice

A lightweight, fully responsive single-page web application designed for learning and practicing Japanese **Hiragana** and **Katakana**[cite: 1]. Built with pure HTML, CSS, and modern JavaScript with zero external build steps or dependencies[cite: 1].

## Features

* **Complete Character Sets**: Covers basic 46 characters, voiced (*dakuten/handakuten*), combined (*yoon*), and foreign sound forms[cite: 1].
* **Multiple Practice Modes**:
  * **Chart**: Interactive character grid with mastery indicators and audio pronunciation[cite: 1].
  * **Read It**: Type the Romaji transcription for a given Kana glyph[cite: 1].
  * **Pick It**: Multiple-choice quiz alternating between reading and writing directions[cite: 1].
  * **Write It**: Canvas-based drawing pad with optional guide overlays to practice stroke writing[cite: 1].
  * **Progress**: Comprehensive stats grid tracking accuracy, streaks, and trouble characters[cite: 1].
* **Spaced Repetition Algorithm**: Intentionally brings back characters you miss more frequently[cite: 1].
* **Persistent Storage**: Automatically saves your mastery progress and preferences using browser storage[cite: 1].
* **Customization**: Switch between Japanese typography styles (**Mincho**, **Gothic**, and **Rounded**)[cite: 1].

## Local Development & Usage

Because this application is self-contained entirely within a single `index.html` file, running it locally requires no installation or node modules.

1. Save the code as `index.html`[cite: 1].
2. Double-click the file to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge)[cite: 1].
